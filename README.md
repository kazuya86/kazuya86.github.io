# kazuya86.github.io

My Asset Calculator(資産管理アプリ)の紹介サイト・ブログ。GitHub Pages(Jekyll)でホスティング。

- `/` — アプリ紹介
- `/asset-calculator/` — 総資産計算
- `/asset-simulation/` — 資産シミュレーション
- `/portfolio/` — ポートフォリオ
- `/net-worth/` — 純資産・総資産
- `/nisa/` — NISA関連
- `/blog/` — ブログ記事一覧

`app-ads.txt` はAdMobのapp-ads.txt検証用に配置しています(触らないでください)。

## 更新方法

`_config.yml` の `app_store_url` を実際のApp StoreのURLに変更してください。共通のヘッダー/フッターは `_layouts/default.html`、スタイルは `assets/css/style.css` にあります。
